💡 Simple Java Program (Without Arrays)

This is a basic Java console program created without using arrays, designed to help beginners understand the core logic of Java programming.
It demonstrates the use of input handling, conditional statements, and arithmetic operations in a clean and easy-to-follow way.

🚀 Features

No arrays used — purely based on simple variables

Focuses on logic building and basic syntax

Beginner-friendly and easy to understand

Teaches how to take input and display results

🧰 Technologies Used

Java (JDK)

Scanner class for user input

Basic operators and conditional logic
